**작성일**: 2026-05-18  
**최종 수정**: 2026-05-18  
**상태**: 진행 중

## 1. Overview

### 배경

서울시 공연·전시 정보는 공공 데이터로 공개되어 있으나, 대부분의 플랫폼은 데이터를 파편화된 형태로 제공하거나 UX가 열악하다. 사용자가 "오늘 내 주변에서 뭘 볼 수 있는지"를 한 번에 확인할 수 있는 서비스가 없다.

### 목표

현재 위치를 기반으로 가까운 공연·전시를 거리순으로 보여주고, 할인 정보를 함께 제공하는 **PWA**를 구축한다. 지도 없이 리스트 중심으로 빠르게 정보를 탐색할 수 있는 경험에 집중한다.

### 경쟁 서비스 대비 차별점

- **위치 기반 거리순 정렬**: 카카오·네이버 지도가 장소를 보여준다면, 이 서비스는 오늘 갈 수 있는 문화 일정을 큐레이션한다.
- **할인 정보 통합**: 공연 리스트와 할인 데이터를 별도 API에서 가져와 매칭, 한 화면에서 확인 가능하다.
- **공공 데이터 활용**: 국가 공식 데이터 기반으로 신뢰도 있는 정보를 제공한다.

## 2. Target User

### Primary — 20~30대 서울 거주 직장인

| 항목 | 내용 |
|---|---|
| 연령 | 20~30대 |
| 특징 | 문화생활에 관심 있으나 정보를 찾는 데 시간을 쓰기 싫어함 |
| Pain Point | 공연·전시 정보가 여러 플랫폼에 흩어져 있고, 내 위치 기준으로 볼 수 없음 |
| 목표 | 오늘 당장 갈 수 있는 가까운 공연·전시를 빠르게 찾고 싶다 |

### Secondary — 서울 방문 국내 관광객

| 항목 | 내용 |
|---|---|
| 연령 | 20~40대 |
| 특징 | 서울에 익숙하지 않고, 이동 거리에 민감함 |
| Pain Point | 서울에서 뭘 볼 수 있는지 모르고, 이동 동선을 고려하기 어려움 |
| 목표 | 지금 있는 위치 근처에서 오늘 즐길 수 있는 문화 콘텐츠를 알고 싶다 |

## 4. Functional Requirements

### 4-1. 홈 화면 (`/`)

| 기능 | 세부 요구사항 |
|---|---|
| 위치 수집 | `navigator.geolocation`으로 현재 위치 수집, 권한 거부 시 안내 메시지 표시 |
| 공연·전시 리스트 | 거리순 정렬, 카드 형태 표시 (공연명, 공연장, 날짜, 거리, 할인 뱃지) |
| 거리 표시 | 각 카드에 공연장까지 거리 표시 (예: 1.2km) |
| 검색바 | 상단 고정, 입력 후 검색 시 검색 결과 화면으로 이동 |
| 할인 필터 | 할인 공연만 보기 토글 버튼, 활성 시 할인 뱃지 있는 항목만 표시 |
| 로딩 상태 | API 호출 중 스켈레톤 UI 표시 |
| 에러 상태 | API 호출 실패 시 에러 메시지 + 재시도 버튼 |

### 4-2. 검색 결과 화면

| 기능 | 세부 요구사항 |
|---|---|
| 검색 결과 리스트 | 검색어 기반 공연·전시 필터링, 홈과 동일한 카드 형태 |
| 결과 없음 처리 | 검색 결과 없을 시 안내 메시지 표시 |
| 뒤로가기 | 홈 화면으로 복귀 |

### 4-3. 상세 화면 (`/detail/:id`)

| 기능 | 세부 요구사항 |
|---|---|
| 공연·전시 정보 | 공연명, 공연장, 날짜·시간, 가격, 할인 뱃지, 상세 설명 |
| 예매 링크 | 외부 예매 사이트로 이동하는 버튼 (새 탭 열기) |
| 없는 항목 처리 | 존재하지 않는 ID 접근 시 안내 메시지 + 홈으로 버튼 |
| 뒤로가기 | 이전 페이지로 이동 |

### 4-4. 공통 — Header

| 기능 | 세부 요구사항 |
|---|---|
| 로고 | 클릭 시 홈으로 이동 |
| 검색바 | 홈 화면 상단에 고정 표시 |
| 고정 헤더 | 스크롤 시 상단 고정 (sticky) |

## 5. Data Source

| API | 제공처 | 역할 | 주요 필드 |
|---|---|---|---|
| 한눈에보는문화정보조회서비스 | 한국문화정보원 | 공연·전시 리스트, 좌표 | `gpsxfrom`(경도), `gpsyfrom`(위도) |
| 문화릴레이티켓 할인조회 | 한국문화정보원 | 할인 정보 | 공연명, 할인율, 할인 기간 |

- 두 API 데이터는 **공연명 또는 공연장명 기준**으로 매칭하여 할인 뱃지 표시

## 9. Out of Scope

아래 기능은 이 프로젝트에서 구현하지 않는다.

| 항목 | 비고 |
|---|---|
| 카카오맵 지도 표시 | 향후 확장 — 카카오맵 API 연동 후 추가 |

| 하루 코스 담기 / 타임라인 | 향후 확장 |
| 코스 공유 (이미지·링크·카카오톡) | 향후 확장 |
| 로그인 / 서버 저장 | 향후 확장 |
| 즐겨찾기 / 히스토리 | 향후 확장 |
| 실시간 내비게이션 | 카카오맵 앱으로 역할 분리, 인앱 구현 없음 |
| 인앱 티켓 결제 | 외부 예매 링크 연결만 제공 |
| 전국 서비스 | MVP는 서울 우선, 이후 확장 구조로 설계 |
